## What I build

我喜歡處理那些「硬體還好好的，只是軟體先離場」的問題，也把氣象電碼、颱風路徑與日常維運需求，整理成能直接使用的工具。

- **IoT Rebuild** — 讓仍能工作的裝置擺脫過時 App 與雲端依賴。
- **Meteorology Tool** — 把專業氣象資料轉成可解析、可比較、可視覺化的資訊。
- **Third-Party Assist Tool** — 用小而實用的桌面工具，消除重複操作與診斷摩擦。
